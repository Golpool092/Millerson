Онлайн калькулятор эллипсоида

Эллипсоид — это поверхность в трёхмерном пространстве, которая получается деформацией сферы вдоль трёх взаимно перпендикулярных осей. Он задаётся тремя полуосями: a, b, c. Наш калькулятор позволяет вычислить:

  • Объём V = (4/3)πabc. Эта формула точная.
  • Площадь поверхности — точной формулы не существует, поэтому используется приближение Кнуда Томсена (p-степенное среднее): S ≈ 4π·( ( (ab)^p + (ac)^p + (bc)^p ) / 3 )^(1/p), где p ≈ 1,6075. Это даёт хорошую точность для большинства форм.

Калькулятор использует это приближение. Введите три полуоси и получите объём и приблизительную площадь поверхности.

Пример расчёта

Полуоси: a = 4 см, b = 3 см, c = 2 см. Тогда объём V = (4/3)π·4·3·2 = (4/3)π·24 = 100,53 см³. Площадь поверхности (приближённо) S ≈ 4π·( ( (12)^1.6075 + (8)^1.6075 + (6)^1.6075 ) / 3 )^(1/1.6075). Вычислив, получим около 91,6 см².

Применение

Эллипсоиды используются в геодезии (форма Земли — геоид, приближаемый эллипсоидом), в физике (тензор инерции), в компьютерной графике, в дизайне.
