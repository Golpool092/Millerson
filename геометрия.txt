Квадрат — это правильный четырёхугольник, у которого все стороны равны и все углы равны 90°.

Обозначения:
a — сторона квадрата
S — площадь
P — периметр
d — диагональ
r — радиус вписанной окружности
R — радиус описанной окружности

S = a² — площадь квадрата равна квадрату его стороны.

P = 4a — периметр квадрата равен сумме четырёх равных сторон.

d = a√2 — диагональ квадрата находится по теореме Пифагора, так как диагональ делит квадрат на два прямоугольных равнобедренных треугольника.

r = a/2 — радиус вписанной окружности равен половине стороны, потому что окружность касается середины каждой стороны.

R = a/√2 — радиус описанной окружности равен половине диагонали квадрата.

a = √S — сторона выражается через площадь как квадратный корень из площади.

a = P/4 — сторона равна четверти периметра.

S = P²/16 — площадь выражается через периметр.

S = d²/2 — площадь выражается через диагональ.

a = d/√2 — сторона выражается через диагональ.

d = 2R — диагональ равна диаметру описанной окружности.

a = 2r — сторона равна диаметру вписанной окружности.

R = a√2/2 — радиус описанной окружности можно выразить через сторону.

r = d/(2√2) — радиус вписанной окружности можно выразить через диагональ.


Прямоугольник — это четырёхугольник, у которого все углы равны 90°.

Обозначения:
a — длина
b — ширина
S — площадь
P — периметр
d — диагональ
α — угол между диагональю и стороной a
β — угол между диагональю и стороной b

S = ab — площадь равна произведению длины на ширину.

P = 2(a + b) — периметр равен удвоенной сумме длины и ширины.

d = √(a² + b²) — диагональ находится по теореме Пифагора.

a = S/b — длина выражается через площадь и ширину.

b = S/a — ширина выражается через площадь и длину.

a = P/2 − b — длина выражается через периметр и ширину.

b = P/2 − a — ширина выражается через периметр и длину.

S = P(a)/2 − a² — площадь через периметр и длину, полученная подстановкой b = P/2 − a.

S = d²·ab/(a² + b²) — связь площади и диагонали через стороны.

d² = a² + b² — квадрат диагонали равен сумме квадратов сторон.

sin α = b/d — синус угла между диагональю и стороной a равен отношению противолежащей стороны к диагонали.

cos α = a/d — косинус этого угла равен отношению прилежащей стороны к диагонали.

tan α = b/a — тангенс угла равен отношению ширины к длине.

R = d/2 — радиус описанной окружности равен половине диагонали.

R = √(a² + b²)/2 — радиус описанной окружности через стороны.

r не существует — вписанная окружность существует только в том случае, если a = b, то есть когда прямоугольник является квадратом.


Параллелограмм — это четырёхугольник, у которого противоположные стороны попарно параллельны и равны.

Обозначения:
a, b — стороны параллелограмма
hₐ — высота, проведённая к стороне a
h_b — высота, проведённая к стороне b
S — площадь
P — периметр
d₁, d₂ — диагонали
α — угол между сторонами a и b

S = a·hₐ — площадь равна произведению стороны на высоту, проведённую к этой стороне.

S = b·h_b — площадь равна произведению другой стороны на соответствующую высоту.

S = ab sinα — площадь равна произведению двух сторон на синус угла между ними.

P = 2(a + b) — периметр равен удвоенной сумме соседних сторон.

hₐ = b sinα — высота к стороне a выражается через сторону b и синус угла между сторонами.

h_b = a sinα — высота к стороне b выражается через сторону a и синус угла.

d₁² = a² + b² − 2ab cosα — квадрат одной диагонали по теореме косинусов.

d₂² = a² + b² + 2ab cosα — квадрат второй диагонали.

d₁² + d₂² = 2(a² + b²) — сумма квадратов диагоналей равна удвоенной сумме квадратов сторон.

S = d₁ d₂ sinφ / 2 — площадь через диагонали и угол φ между ними.

a = S/hₐ — сторона выражается через площадь и соответствующую высоту.

b = S/h_b — вторая сторона выражается через площадь и соответствующую высоту.

sinα = S/(ab) — синус угла выражается через площадь и стороны.

cosα = (a² + b² − d₁²)/(2ab) — косинус угла через стороны и диагональ.


Ромб — это параллелограмм, у которого все стороны равны.

Обозначения:
a — сторона ромба
h — высота, опущенная на сторону
S — площадь
P — периметр
d₁, d₂ — диагонали
α — угол ромба
r — радиус вписанной окружности
R — радиус описанной окружности

S = a·h — площадь равна произведению стороны на высоту.

S = a² sinα — площадь равна квадрату стороны, умноженному на синус угла между сторонами.

S = (d₁·d₂)/2 — площадь равна половине произведения диагоналей.

P = 4a — периметр равен сумме четырёх равных сторон.

h = a sinα — высота выражается через сторону и синус угла.

d₁ = 2a cos(α/2) — одна диагональ выражается через сторону и половину угла.

d₂ = 2a sin(α/2) — вторая диагональ выражается через сторону и половину угла.

d₁² + d₂² = 4a² — сумма квадратов диагоналей равна четырём квадратам стороны.

a = P/4 — сторона выражается через периметр.

a = √(S / sinα) — сторона выражается через площадь и угол.

S = r·P/2 — площадь равна произведению радиуса вписанной окружности на полупериметр.

r = S/(2a) — радиус вписанной окружности выражается через площадь и сторону.

r = h/2 — радиус вписанной окружности равен половине высоты.

R = a/2 — радиус описанной окружности существует только если α = 90°, то есть когда ромб является квадратом.


Трапеция — это четырёхугольник, у которого две стороны параллельны. Эти параллельные стороны называются основаниями.

Обозначения:
a, b — основания трапеции
c, d — боковые стороны
h — высота
S — площадь
P — периметр
m — средняя линия
d₁, d₂ — диагонали
α, β — углы при основании a

S = (a + b)/2 · h — площадь равна полусумме оснований, умноженной на высоту.

S = m·h — площадь равна произведению средней линии на высоту.

m = (a + b)/2 — средняя линия равна полусумме оснований.

P = a + b + c + d — периметр равен сумме всех сторон.

h = 2S/(a + b) — высота выражается через площадь и основания.

a + b = 2m — сумма оснований равна удвоенной средней линии.

S = (a + b)/2 · c sinα — площадь через боковую сторону и угол при основании.

h = c sinα — высота выражается через боковую сторону и угол при основании.

d₁² = ab + c² + 2ac cosα — квадрат диагонали через стороны и угол.

d₂² = ab + d² + 2bd cosβ — квадрат второй диагонали.

Для равнобедренной трапеции, где c = d:

d₁ = d₂ — диагонали равны.

R существует — описанная окружность существует только у равнобедренной трапеции.

S = (a + b)/2 · √(c² − ((b − a)/2)²) — площадь равнобедренной трапеции через основания и боковую сторону.


Треугольник — это многоугольник с тремя сторонами и тремя углами.

Обозначения:
a, b, c — стороны треугольника
α, β, γ — углы, лежащие напротив сторон a, b, c соответственно
hₐ — высота, проведённая к стороне a
mₐ — медиана к стороне a
lₐ — биссектриса угла α
S — площадь
P — периметр
p — полупериметр
R — радиус описанной окружности
r — радиус вписанной окружности

P = a + b + c — периметр равен сумме сторон.

p = (a + b + c)/2 — полупериметр равен половине периметра.

S = 1/2 a·hₐ — площадь равна половине произведения стороны на высоту к ней.

hₐ = 2S/a — высота выражается через площадь и сторону.

S = 1/2 ab sinγ — площадь через две стороны и угол между ними.

S = pr — площадь равна произведению полупериметра на радиус вписанной окружности.

S = abc/(4R) — площадь через стороны и радиус описанной окружности.

S = √(p(p − a)(p − b)(p − c)) — формула Герона для площади.

a² = b² + c² − 2bc cosα — теорема косинусов.

b² = a² + c² − 2ac cosβ — аналогичная формула для стороны b.

c² = a² + b² − 2ab cosγ — аналогичная формула для стороны c.

a/sinα = b/sinβ = c/sinγ = 2R — теорема синусов и связь со вписанной окружностью.

R = a/(2 sinα) — радиус описанной окружности через сторону и противолежащий угол.

R = abc/(4S) — радиус описанной окружности через стороны и площадь.

r = S/p — радиус вписанной окружности через площадь и полупериметр.

r = 2S/(a + b + c) — радиус вписанной окружности через площадь и периметр.

a² = b² + c² — теорема Пифагора для прямоугольного треугольника, где α = 90°.

R = c/2 — радиус описанной окружности прямоугольного треугольника равен половине гипотенузы.

mₐ = 1/2 √(2b² + 2c² − a²) — длина медианы к стороне a.

S = mₐ·a/2 — площадь можно выразить через медиану и сторону при известном угле между ними.

lₐ = 2bc cos(α/2)/(b + c) — длина биссектрисы угла α.

lₐ² = bc(1 − a²/(b + c)²) — формула биссектрисы через стороны.

hₐ = b sinγ = c sinβ — высота выражается через сторону и прилежащий угол.

S = (abc)/(4R) = pr — равенство различных формул площади.


Равносторонний треугольник — это треугольник, у которого все стороны равны и все углы равны 60°.

Обозначения:
a — сторона
h — высота
S — площадь
P — периметр
p — полупериметр
R — радиус описанной окружности
r — радиус вписанной окружности
m — медиана
l — биссектриса

P = 3a — периметр равен сумме трёх равных сторон.

p = 3a/2 — полупериметр равен половине периметра.

S = a²√3/4 — площадь через сторону.

S = 1/2 a·h — площадь через сторону и высоту.

h = a√3/2 — высота равна стороне, умноженной на √3/2.

a = 2h/√3 — сторона выражается через высоту.

R = a/√3 — радиус описанной окружности.

R = 2h/3 — радиус описанной окружности через высоту.

r = a√3/6 — радиус вписанной окружности.

r = h/3 — радиус вписанной окружности равен трети высоты.

S = pr — площадь через полупериметр и радиус вписанной окружности.

S = a·r·3/2 — площадь через сторону и радиус вписанной окружности.

m = h — медиана равна высоте.

l = h — биссектриса равна высоте.

R = 2r — радиус описанной окружности в два раза больше радиуса вписанной окружности.


Окружность — это множество точек плоскости, находящихся на одинаковом расстоянии от одной точки, называемой центром. Круг — это часть плоскости, ограниченная окружностью.

Обозначения:
R — радиус
d — диаметр
L — длина окружности
S — площадь круга
π — число пи
(a, b) — координаты центра
α — центральный угол в радианах
l — длина хорды
s — длина дуги
θ — центральный угол в градусах

d = 2R — диаметр равен удвоенному радиусу.

R = d/2 — радиус равен половине диаметра.

L = 2πR — длина окружности через радиус.

L = πd — длина окружности через диаметр.

S = πR² — площадь круга через радиус.

S = πd²/4 — площадь круга через диаметр.

(x − a)² + (y − b)² = R² — уравнение окружности с центром в точке (a, b).

x² + y² = R² — уравнение окружности с центром в начале координат.

l = 2R sin(α/2) — длина хорды через радиус и центральный угол в радианах.

α = 2 arcsin(l/(2R)) — центральный угол через хорду и радиус.

s = Rα — длина дуги, если угол задан в радианах.

s = πRθ/180 — длина дуги, если угол задан в градусах.

S_сектора = R²α/2 — площадь сектора при угле в радианах.

S_сектора = πR²θ/360 — площадь сектора при угле в градусах.

S_сегмента = R²(α − sinα)/2 — площадь кругового сегмента через угол в радианах.

R = L/(2π) — радиус через длину окружности.

R = √(S/π) — радиус через площадь круга.


Сектор — это часть круга, ограниченная двумя радиусами и дугой между ними.

Обозначения:
R — радиус круга
α — центральный угол в радианах
θ — центральный угол в градусах
S — площадь сектора
L — длина дуги
P — периметр сектора

S = αR²/2 — площадь сектора, если угол задан в радианах.

S = πR²θ/360 — площадь сектора, если угол задан в градусах.

L = αR — длина дуги при угле в радианах.

L = 2πRθ/360 — длина дуги при угле в градусах.

α = L/R — центральный угол в радианах через длину дуги.

θ = 360L/(2πR) — центральный угол в градусах через длину дуги.

P = 2R + L — периметр сектора равен сумме двух радиусов и дуги.

S = RL/2 — площадь сектора через радиус и длину дуги.

R = √(2S/α) — радиус через площадь и угол в радианах.

R = L/α — радиус через длину дуги и угол в радианах.




Эллипс — это множество точек плоскости, сумма расстояний от которых до двух фиксированных точек, называемых фокусами, постоянна.

Обозначения:
a — большая полуось
b — малая полуось
c — фокальное расстояние (расстояние от центра до фокуса)
S — площадь
L — длина периметра
e — эксцентриситет
(x₀, y₀) — координаты центра

S = πab — площадь эллипса равна произведению числа π на большую и малую полуоси.

c² = a² − b² — связь полуосей и фокального расстояния (при a ≥ b).

c = √(a² − b²) — фокальное расстояние через полуоси.

e = c/a — эксцентриситет эллипса.

e = √(1 − b²/a²) — эксцентриситет через полуоси.

a² = b² + c² — выражение большой полуоси через малую полуось и фокальное расстояние.

b² = a²(1 − e²) — малая полуось через большую полуось и эксцентриситет.

x²/a² + y²/b² = 1 — каноническое уравнение эллипса с центром в начале координат и большой полуосью по оси x.

(x − x₀)²/a² + (y − y₀)²/b² = 1 — уравнение эллипса с центром в точке (x₀, y₀).

L ≈ 2π√((a² + b²)/2) — приближённая формула длины периметра эллипса.

L ≈ π[3(a + b) − √((3a + b)(a + 3b))] — более точная приближённая формула периметра.

S = πa²√(1 − e²) — площадь через большую полуось и эксцентриситет


Правильный многоугольник — это многоугольник, у которого все стороны и все углы равны.

Обозначения:
n — число сторон
a — сторона
P — периметр
S — площадь
r — апофема, радиус вписанной окружности
R — радиус описанной окружности
α — центральный угол в радианах

P = na — периметр равен произведению числа сторон на длину стороны.

α = 2π/n — центральный угол правильного n-угольника.

S = 1/2 P·r — площадь через периметр и апофему.

S = n a² / (4 tan(π/n)) — площадь через сторону и число сторон.

S = 1/2 nR² sin(2π/n) — площадь через радиус описанной окружности.

r = a / (2 tan(π/n)) — апофема через сторону и число сторон.

R = a / (2 sin(π/n)) — радиус описанной окружности через сторону.

a = 2R sin(π/n) — сторона через радиус описанной окружности.

a = 2r tan(π/n) — сторона через апофему.

r = R cos(π/n) — связь радиусов вписанной и описанной окружностей.

R = r / cos(π/n) — радиус описанной окружности через апофему.

S = nr² tan(π/n) — площадь через апофему и число сторон.

S = PR/2 · cos(π/n) — площадь через периметр и радиус описанной окружности.



Куб — это правильный шестигранник, у которого все рёбра равны и все грани являются квадратами.

Обозначения:
a — ребро куба
V — объём
S — площадь полной поверхности
S₁ — площадь одной грани
d — пространственная диагональ
dₗ — диагональ грани
r — радиус вписанной сферы
R — радиус описанной сферы

V = a³ — объём куба равен кубу ребра.

S = 6a² — площадь полной поверхности равна сумме площадей шести граней.

S₁ = a² — площадь одной грани.

dₗ = a√2 — диагональ грани по теореме Пифагора.

Параллелепипед — это многогранник, у которого все грани являются параллелограммами. Прямоугольный параллелепипед имеет прямые углы между рёбрами.

S₂ = bc — площадь второй грани.

d² = a² + b² + c² + 2(ab cosγ + bc cosα + ac cosβ) — квадрат пространственной диагонали общего параллелепипеда.


Призма — это многогранник, у которого две грани являются равными и параллельными многоугольниками (основания), а остальные грани — параллелограммы.

Пирамида — это многогранник, у которого основание является многоугольником, а остальные грани — треугольники, сходящиеся в одной вершине.

Тригонометрия — раздел математики, изучающий зависимости между сторонами и углами треугольников, а также свойства тригонометрических функций.

Обозначения:
α, β — углы
a — противолежащий катет
b — прилежащий катет
c — гипотенуза
π — число пи

sinα = a/c — синус угла равен отношению противолежащего катета к гипотенузе.

cosα = b/c — косинус угла равен отношению прилежащего катета к гипотенузе.

tanα = a/b — тангенс угла равен отношению противолежащего катета к прилежащему.

ctgα = b/a — котангенс угла равен отношению прилежащего катета к противолежащему.

sin²α + cos²α = 1 — основное тригонометрическое тождество.

1 + tan²α = 1/cos²α — тождество для тангенса.

1 + ctg²α = 1/sin²α — тождество для котангенса.

tanα = sinα/cosα — выражение тангенса через синус и косинус.

ctgα = cosα/sinα — выражение котангенса через синус и косинус.

sin(α ± β) = sinα cosβ ± cosα sinβ — формула суммы и разности синуса.

cos(α ± β) = cosα cosβ ∓ sinα sinβ — формула суммы и разности косинуса.

tan(α ± β) = (tanα ± tanβ)/(1 ∓ tanα tanβ) — формула суммы и разности тангенса.

sin2α = 2 sinα cosα — формула двойного угла для синуса.

cos2α = cos²α − sin²α — формула двойного угла для косинуса.

cos2α = 2cos²α − 1 — альтернативная форма формулы двойного угла.

cos2α = 1 − 2sin²α — альтернативная форма формулы двойного угла.

tan2α = 2tanα/(1 − tan²α) — формула двойного угла для тангенса.

sin3α = 3sinα − 4sin³α — формула тройного угла для синуса.

cos3α = 4cos³α − 3cosα — формула тройного угла для косинуса.

Формулы понижения степени:

sin²α = (1 − cos2α)/2 — выражение квадрата синуса через двойной угол.

cos²α = (1 + cos2α)/2 — выражение квадрата косинуса через двойной угол.

Формулы приведения:

sin(π − α) = sinα

sin(π + α) = −sinα

cos(π − α) = −cosα

cos(π + α) = −cosα

Периодичность:

sin(α + 2π) = sinα

cos(α + 2π) = cosα

tan(α + π) = tanα

Алгебра — раздел математики, изучающий выражения, уравнения и преобразования с переменными.

Обозначения:
a, b — переменные или числа

(a + b)² = a² + 2ab + b² — квадрат суммы.

(a − b)² = a² − 2ab + b² — квадрат разности.

a² − b² = (a − b)(a + b) — разность квадратов.

(a + b)³ = a³ + 3a²b + 3ab² + b³ — куб суммы.

(a − b)³ = a³ − 3a²b + 3ab² − b³ — куб разности.

a³ + b³ = (a + b)(a² − ab + b²) — сумма кубов.

a³ − b³ = (a − b)(a² + ab + b²) — разность кубов.

(a + b)(a − b) = a² − b² — произведение суммы и разности.

(a + b + c)² = a² + b² + c² + 2ab + 2ac + 2bc — квадрат суммы трёх слагаемых.

(a + b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴ — четвёртая степень суммы.

(a − b)⁴ = a⁴ − 4a³b + 6a²b² − 4ab³ + b⁴ — четвёртая степень разности.

(a + b)ⁿ — разложение по формуле бинома Ньютона:

(a + b)ⁿ = C(n,0)aⁿ + C(n,1)aⁿ⁻¹b + C(n,2)aⁿ⁻²b² + … + C(n,n)bⁿ,

где C(n,k) = n! / (k!(n − k)!) — биномиальные коэффициенты.


Квадратное уравнение — это уравнение второй степени с одной переменной.

Обозначения:
a — коэффициент при x², a ≠ 0
b — коэффициент при x
c — свободный член
x — переменная
D — дискриминант
x₁, x₂ — корни уравнения

ax² + bx + c = 0 — общий вид квадратного уравнения.

D = b² − 4ac — дискриминант.

Если D > 0, уравнение имеет два различных действительных корня.

Если D = 0, уравнение имеет один действительный корень.

Если D < 0, действительных корней нет.

x = (−b ± √D) / 2a — формула корней квадратного уравнения.

x₁ = (−b + √D) / 2a — первый корень.

x₂ = (−b − √D) / 2a — второй корень.

x = −b/(2a) — корень при D = 0.

x₁ + x₂ = −b/a — сумма корней по теореме Виета.

x₁x₂ = c/a — произведение корней по теореме Виета.

a(x − x₁)(x − x₂) = 0 — разложение квадратного трёхчлена через корни.

x² + px + q = 0 — приведённое квадратное уравнение, где p = b/a, q = c/a.

x = −p/2 ± √(p²/4 − q) — формула корней приведённого уравнения.

ax² + bx + c = a(x + b/(2a))² − D/(4a) — выделение полного квадрата.



Арифметическая прогрессия — это последовательность, в которой каждый следующий член отличается от предыдущего на одно и то же число.

Обозначения:
a₁ — первый член
aₙ — n-й член
d — разность прогрессии
n — номер члена
Sₙ — сумма первых n членов

aₙ = a₁ + (n − 1)d — формула n-го члена.

aₙ = aₙ₋₁ + d — рекуррентная формула прогрессии.

d = aₙ − aₙ₋₁ — разность прогрессии.

d = (aₙ − a₁)/(n − 1) — разность через первый и n-й член.

Sₙ = n/2 (a₁ + aₙ) — сумма первых n членов через первый и n-й член.

Sₙ = n/2 (2a₁ + (n − 1)d) — сумма через первый член и разность.

a₁ = aₙ − (n − 1)d — первый член через n-й.

n = (aₙ − a₁)/d + 1 — номер члена через значения прогрессии.

S₂n = 2n/2 (a₁ + a₂n) — сумма первых 2n членов.



Геометрическая прогрессия — это последовательность, в которой каждый следующий член получается умножением предыдущего на одно и то же число.

Обозначения:
b₁ — первый член
bₙ — n-й член
q — знаменатель прогрессии
n — номер члена
Sₙ — сумма первых n членов

bₙ = b₁ qⁿ⁻¹ — формула n-го члена.

bₙ = bₙ₋₁ q — рекуррентная формула прогрессии.

q = bₙ / bₙ₋₁ — знаменатель прогрессии.

q = (bₙ / b₁)^(1/(n − 1)) — знаменатель через первый и n-й член.

Sₙ = b₁ (qⁿ − 1)/(q − 1), при q ≠ 1 — сумма первых n членов.

Sₙ = b₁ (1 − qⁿ)/(1 − q), при q ≠ 1 — эквивалентная форма записи суммы.

Sₙ = nb₁, при q = 1 — сумма, если прогрессия постоянная.

b₁ = bₙ / qⁿ⁻¹ — первый член через n-й.

n = 1 + log(bₙ / b₁)/log q — номер члена через значения прогрессии, при q > 0, q ≠ 1.

S∞ = b₁/(1 − q), при |q| < 1 — сумма бесконечной убывающей геометрической прогрессии.



Логарифм — это показатель степени, в которую нужно возвести основание, чтобы получить заданное число.

Обозначения:
a — основание логарифма, a > 0, a ≠ 1
x, y — положительные числа
n — действительное число
ln — натуральный логарифм, основание e

logₐ(xy) = logₐx + logₐy — логарифм произведения равен сумме логарифмов.

logₐ(x/y) = logₐx − logₐy — логарифм частного равен разности логарифмов.

logₐ(xⁿ) = n logₐx — логарифм степени равен произведению показателя на логарифм основания степени.

logₐ1 = 0 — логарифм единицы равен нулю.

logₐa = 1 — логарифм основания по тому же основанию равен единице.

a^{logₐx} = x — основное свойство логарифма.

logₐ(a^x) = x — логарифм степени с тем же основанием равен показателю.

logₐb = ln b / ln a — формула перехода к новому основанию через натуральный логарифм.

logₐb = log_c b / log_c a — формула перехода к любому новому основанию c.

Если a > 1, функция logₐx возрастает.

Если 0 < a < 1, функция logₐx убывает.


Производная — это предел отношения приращения функции к приращению аргумента, характеризующий скорость изменения функции.

Обозначения:
f(x) — функция
f′(x) — производная функции
n — число
u, v — функции переменной x
C — константа

(xⁿ)' = n xⁿ⁻¹ — производная степени.

(C)' = 0 — производная постоянной равна нулю.

(Cf)' = C f′ — производная произведения функции на константу.

(u ± v)' = u′ ± v′ — производная суммы и разности.

(sin x)' = cos x — производная синуса.

(cos x)' = −sin x — производная косинуса.

(tan x)' = 1/cos²x — производная тангенса.

(ctg x)' = −1/sin²x — производная котангенса.

(eˣ)' = eˣ — производная экспоненты с основанием e.

(aˣ)' = aˣ ln a — производная показательной функции с основанием a > 0.

(ln x)' = 1/x — производная натурального логарифма.

(logₐx)' = 1/(x ln a) — производная логарифма по основанию a.

(fg)' = f′g + fg′ — правило производной произведения.

(f/g)' = (f′g − fg′)/g² — правило производной частного.

(f(g(x)))' = f′(g(x))·g′(x) — правило цепочки.

(x^x)' = x^x(ln x + 1) — производная функции x^x.


Интеграл — это операция, обратная дифференцированию. Неопределённый интеграл представляет собой множество первообразных функции.

Обозначения:
∫ — знак интеграла
f(x) — подынтегральная функция
F(x) — первообразная, где F′(x) = f(x)
C — произвольная постоянная
n — число, n ≠ −1

∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C — интеграл степени при n ≠ −1.

∫ 1/x dx = ln|x| + C — интеграл при n = −1.

∫ eˣ dx = eˣ + C — интеграл экспоненты с основанием e.

∫ aˣ dx = aˣ/ln a + C, при a > 0, a ≠ 1 — интеграл показательной функции.

∫ sin x dx = −cos x + C — интеграл синуса.

∫ cos x dx = sin x + C — интеграл косинуса.

∫ 1/cos²x dx = tan x + C — интеграл 1/cos²x.

∫ 1/sin²x dx = −ctg x + C — интеграл 1/sin²x.

∫ 1/(1 + x²) dx = arctan x + C — интеграл стандартной дроби.

∫ 1/√(1 − x²) dx = arcsin x + C — интеграл с корнем.

∫ f′(x)/f(x) dx = ln|f(x)| + C — интеграл логарифмического типа.

∫ u dv = uv − ∫ v du — формула интегрирования по частям.

∫ f(g(x)) g′(x) dx = ∫ f(t) dt — замена переменной, где t = g(x).

Аналитическая геометрия — раздел математики, изучающий геометрические объекты с помощью координат и алгебраических уравнений.

Обозначения:
(x₁, y₁), (x₂, y₂) — координаты точек
(x₀, y₀) — координаты точки
A, B, C — коэффициенты общего уравнения прямой
k — угловой коэффициент
b — свободный член
d — расстояние

d = √((x₂ − x₁)² + (y₂ − y₁)²) — расстояние между двумя точками на плоскости.

xср = (x₁ + x₂)/2 — абсцисса середины отрезка.

yср = (y₁ + y₂)/2 — ордината середины отрезка.

k = (y₂ − y₁)/(x₂ − x₁) — угловой коэффициент прямой, проходящей через две точки, при x₂ ≠ x₁.

y = kx + b — уравнение прямой с угловым коэффициентом.

b = y₀ − kx₀ — свободный член через точку и коэффициент наклона.

y − y₀ = k(x − x₀) — уравнение прямой через точку с угловым коэффициентом.

Ax + By + C = 0 — общее уравнение прямой.

k = −A/B — угловой коэффициент через коэффициенты общего уравнения, при B ≠ 0.

d = |Ax₀ + By₀ + C| / √(A² + B²) — расстояние от точки до прямой.

(x − a)² + (y − b)² = R² — уравнение окружности с центром в точке (a, b).

x² + y² = R² — уравнение окружности с центром в начале координат.

(x − x₁)/(x₂ − x₁) = (y − y₁)/(y₂ − y₁) — параметрическая форма прямой через две точки.

cosφ = (A₁A₂ + B₁B₂) / (√(A₁² + B₁²) √(A₂² + B₂²)) — угол между двумя прямыми, заданными уравнениями A₁x + B₁y + C₁ = 0 и A₂x + B₂y + C₂ = 0.
