Фокусы эллипса

Определение, расположение, формулы, свойства и интерактивный калькулятор. Полный калькулятор эллипса →

Определение

Фокусы эллипса — две фиксированные точки, расположенные внутри эллипса на его большой оси, для которых выполняется основное свойство: сумма расстояний от любой точки эллипса до фокусов постоянна и равна длине большой оси (2a).

Формулы для фокусов

c = √(a² − b²)
F₁ = (−c, 0), F₂ = (c, 0)
F₁ = (0, −c), F₂ = (0, c) (вертикальная ось)

где a — большая полуось, b — малая полуось, c — фокусное расстояние. Если большая ось горизонтальна, фокусы лежат на оси X; если вертикальна — на оси Y.

Свойства фокусов

  • Сумма расстояний от любой точки эллипса до фокусов равна 2a.
  • Расстояние между фокусами равно 2c.
  • Фокусы всегда лежат на большой оси.
  • Для окружности (a = b) фокусы совпадают с центром (c = 0).
  • Эллипс можно построить с помощью нити, закреплённой в фокусах (садовый способ).

Примеры вычислений

Пример 1. Эллипс с полуосями a = 5 см, b = 3 см. Найти фокусы.
c = √(25 − 9) = 4 см. Фокусы: F₁(−4, 0), F₂(4, 0).

Пример 2. Эллипс с вертикальной большой осью: a = 6 см, b = 4 см. Найти фокусы.
c = √(36 − 16) = √20 ≈ 4,472 см. Фокусы: F₁(0, −4,472), F₂(0, 4,472).

Пример 3. Расстояние между фокусами равно 8 см, большая полуось 5 см. Найти малую полуось.
c = 4 см, b = √(a² − c²) = √(25 − 16) = 3 см.

По большой полуоси и фокусному расстоянию

Задачи для самостоятельного решения

  1. Эллипс с полуосями a = 8 см, b = 5 см. Найдите координаты фокусов (горизонтальная ось).
  2. Расстояние между фокусами равно 10 см, большая полуось 7 см. Найдите малую полуось.
  3. Фокусы эллипса находятся в точках (±6, 0), большая полуось равна 10 см. Найдите малую полуось и эксцентриситет.

Часто задаваемые вопросы

Что такое фокусы эллипса?

Фокусы эллипса — две точки внутри эллипса, для которых сумма расстояний от любой точки эллипса до фокусов постоянна и равна 2a.

Как найти фокусы эллипса?

Сначала находят фокусное расстояние c = √(a² − b²). Затем, если большая ось горизонтальна, фокусы имеют координаты (±c, 0); если вертикальна — (0, ±c).

Чему равно расстояние между фокусами?

Расстояние между фокусами равно 2c, где c = √(a² − b²).

Где находятся фокусы эллипса с полуосями 5 и 3?

c = 4, фокусы: (±4, 0).
