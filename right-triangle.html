Калькулятор прямоугольного треугольника: катеты, гипотенуза, площадь, периметр, высота, радиусы

Прямоугольный треугольник — это треугольник, у которого один угол прямой (90°). Наш онлайн калькулятор позволяет найти все его параметры, зная либо два катета, либо гипотенузу и один катет. Выберите подходящий способ задания, введите значения и получите мгновенный результат с подробным решением.

Основные формулы прямоугольного треугольника

Теорема Пифагора: c² = a² + b², где a, b — катеты, c — гипотенуза.
Периметр: P = a + b + c.
Площадь: S = ½ab.
Высота к гипотенузе: h_c = ab / c.
Радиус вписанной окружности: r = (a + b - c) / 2.
Радиус описанной окружности: R = c / 2 (центр — середина гипотенузы).

Примеры решения

Пример 1: Катеты 3 см и 4 см. Найти гипотенузу, площадь, периметр, высоту и радиусы.
Решение: c = √(3²+4²) = 5 см; P = 3+4+5 = 12 см; S = ½·3·4 = 6 см²; h_c = 3·4/5 = 2,4 см; r = (3+4-5)/2 = 1 см; R = 5/2 = 2,5 см.

Пример 2: Гипотенуза 5 см, катет 3 см. Найти второй катет.
Решение: b = √(5²-3²) = 4 см. Далее все остальные параметры.

Применение в жизни

Прямоугольные треугольники повсеместно используются в строительстве (расчёт стропил, лестниц), в навигации, в физике (разложение векторов).

Часто задаваемые вопросы

Как найти гипотенузу по катетам?
По теореме Пифагора: c = √(a² + b²).
Чему равна площадь прямоугольного треугольника?
S = ½·a·b.
Как найти радиус описанной окружности?
R = c/2.
Как найти радиус вписанной окружности?
r = (a + b - c)/2.
