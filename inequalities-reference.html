Справочник по неравенствам

Свойства неравенств

  • При сложении одного числа к обеим частям знак не меняется
  • При умножении на положительное — знак не меняется
  • При умножении на отрицательное — знак меняется на противоположный!
  • Транзитивность: если a < b и b < c, то a < c

Линейное неравенство ax + b > 0

УсловиеРешение
a > 0x > −b/a
a < 0x < −b/a
a = 0, b > 0Все x (ℝ)

Квадратное неравенство ax² + bx + c > 0

  • Найти корни x₁, x₂ (если D > 0)
  • Схема знаков: при a > 0 парабола ветвями вверх (+)(−)(+)
  • При D < 0: если a > 0 — всегда > 0; если a < 0 — всегда < 0

  • 1 < x < 3 → интервал (1; 3)

Часто задаваемые вопросы

Почему при умножении на -1 знак меняется?
Например, 3 > 2, но -3 < -2. Умножение на отрицательное меняет порядок числовой оси.
Как решить |x−2| < 5?
−5 < x−2 < 5 → −3 < x < 7. Ответ: x ∈ (−3; 7).
Что такое система неравенств?
Набор неравенств, которые должны выполняться одновременно. Ответ — пересечение решений.
Как записать множество решений?
Через интервалы: скобка ( или ) для строгих, [ или ] для нестрогих неравенств.
