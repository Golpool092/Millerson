Диагональ прямоугольника

Формула, вывод, свойства, связь с описанной окружностью, интерактивный калькулятор. Полный калькулятор прямоугольника →

Основная формула диагонали прямоугольника

d = √(a² + b²)

где a и b — стороны прямоугольника. Формула следует из теоремы Пифагора.

Вывод формулы через теорему Пифагора

Диагональ делит прямоугольник на два прямоугольных треугольника с катетами a и b. Гипотенуза каждого треугольника равна диагонали d. По теореме Пифагора: d² = a² + b², откуда d = √(a² + b²).

Свойства диагонали прямоугольника

  • Диагонали прямоугольника равны.
  • Точка пересечения диагоналей делит каждую пополам.
  • Диагональ является диаметром описанной окружности: d = 2R.
  • Квадрат диагонали равен сумме квадратов сторон: d² = a² + b².

Выражение диагонали через другие величины

  • Через площадь S и одну сторону: d = √(a² + (S/a)²)
  • Через периметр P и одну сторону: d = √(a² + (P/2 − a)²)
  • Через радиус описанной окружности R: d = 2R

Примеры вычислений

Пример 1. Стороны прямоугольника 6 см и 8 см. Диагональ: d = √(6²+8²) = √(36+64) = √100 = 10 см.

Пример 2. Площадь прямоугольника 48 см², одна сторона 6 см. Найти диагональ. Вторая сторона b = 48/6 = 8 см, d = √(6²+8²) = 10 см.

Пример 3. Радиус описанной окружности прямоугольника 5 см. Найти диагональ. d = 2·5 = 10 см.

Задачи для самостоятельного решения

  2. Диагональ прямоугольника равна 13 см, одна сторона 5 см. Найдите вторую сторону и площадь.
  3. Периметр прямоугольника 34 см, одна сторона 7 см. Найдите диагональ.
  4. Радиус описанной окружности прямоугольника 6,5 см, одна сторона 5 см. Найдите диагональ и вторую сторону.

Часто задаваемые вопросы

Как найти диагональ прямоугольника, зная стороны?

Извлеките квадратный корень из суммы квадратов сторон: d = √(a² + b²).

Как найти сторону прямоугольника по диагонали и другой стороне?

b = √(d² − a²).

Как диагональ связана с радиусом описанной окружности?

Диагональ равна диаметру описанной окружности: d = 2R.
