Дискриминант квадратного уравнения

Что такое дискриминант?

Дискриминант квадратного уравнения ax² + bx + c = 0 вычисляется по формуле: D = b² − 4ac.

Знак дискриминанта и количество корней

  • D > 0 — два различных вещественных корня
  • D = 0 — один корень (двукратный): x = −b/(2a)
  • D < 0 — нет вещественных корней (два комплексных)

Формула корней

x₁,₂ = (−b ± √D) / (2a)

Теорема Виета

Для корней x₁ и x₂: x₁ + x₂ = −b/a и x₁ · x₂ = c/a.

Применение теоремы Виета

  • Проверка корней без их вычисления
  • Составление уравнения по известным корням
  • Нахождение одного корня по другому

Неполные квадратные уравнения

При b=0: ax²+c=0 → x=±√(−c/a). При c=0: ax²+bx=0 → x(ax+b)=0 → x=0 или x=−b/a.

Часто задаваемые вопросы

Почему формула называется «дискриминант»?
От лат. discrimino — различать. Он «различает» типы решений уравнения.
Как проверить правильность корней?
Подставьте в исходное уравнение или используйте теорему Виета: x₁+x₂=−b/a, x₁·x₂=c/a.
Можно ли найти корни без дискриминанта?
Да: разложением на множители, по теореме Виета, подбором или методом дополнения до квадрата.
Что такое приведённое квадратное уравнение?
Уравнение с a=1: x²+px+q=0. Корни: x₁+x₂=−p, x₁·x₂=q.
