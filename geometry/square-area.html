Площадь квадрата

Формула, примеры, связь с диагональю и периметром, интерактивный калькулятор.

Основная формула площади квадрата

S = a²

где a — сторона квадрата.

Формула площади через диагональ

S = d² / 2

где d — диагональ квадрата. Это следует из того, что d² = 2a².

Связь площади с другими величинами

  • Через периметр P: S = P² / 16
  • Через радиус вписанной окружности r: S = 4r²
  • Через радиус описанной окружности R: S = 2R²

Примеры вычислений

Пример 1. Сторона квадрата равна 5 см. Площадь: S = 5² = 25 см².

Пример 2. Диагональ квадрата равна 8 см. Площадь: S = 8² / 2 = 64 / 2 = 32 см².

Пример 3. Периметр квадрата 40 см. Найти площадь. Сторона a = 40/4 = 10 см, S = 10² = 100 см².

Задачи для самостоятельного решения

  1. Сторона квадрата 12 см. Найдите площадь.
  2. Площадь квадрата 81 см². Найдите сторону и периметр.
  3. Диагональ квадрата 10 см. Найдите площадь.
  4. Радиус описанной окружности квадрата 4√2 см. Найдите площадь.

Часто задаваемые вопросы

Как найти площадь квадрата, зная сторону?

Возведите сторону в квадрат: S = a².

Как найти площадь квадрата по диагонали?

Разделите квадрат диагонали на два: S = d² / 2.

Можно ли найти площадь, зная периметр?

Да, сначала найдите сторону a = P/4, затем S = a².
