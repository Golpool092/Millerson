Диагональ квадрата

Формула, вывод, свойства, связь с описанной окружностью и интерактивный калькулятор.

Формула диагонали квадрата

d = a · √2

где a — сторона квадрата, d — его диагональ.

Вывод формулы через теорему Пифагора

Квадрат — это прямоугольник с равными сторонами. Диагональ делит квадрат на два равных прямоугольных треугольника, где катеты — стороны квадрата (a), а гипотенуза — диагональ (d). По теореме Пифагора:

d² = a² + a² = 2a²

Извлекая квадратный корень, получаем d = a√2.

Свойства диагонали квадрата

  • Диагонали квадрата равны между собой.
  • Они пересекаются под прямым углом (90°).
  • Точка пересечения делит каждую диагональ пополам.
  • Диагонали являются биссектрисами углов квадрата (делят углы 90° на 45°).
  • Квадрат диагонали равен удвоенному квадрату стороны: d² = 2a².
  • Диагональ квадрата всегда больше его стороны примерно в 1,414 раза.

Связь диагонали и радиуса описанной окружности

Описанная окружность квадрата проходит через все его вершины. Диагональ квадрата является диаметром этой окружности:

d = 2R

где R — радиус описанной окружности. Следовательно, радиус можно найти как половину диагонали: R = d/2.

Примеры вычислений

Пример 1. Сторона квадрата равна 6 см. Найти диагональ.
d = 6 · √2 ≈ 6 · 1,4142 = 8,485 см.

Пример 2. Диагональ квадрата равна 10 см. Найти сторону.
a = d / √2 = 10 / 1,4142 ≈ 7,071 см.

Пример 3. Радиус описанной окружности квадрата равен 4 см. Найти диагональ.
d = 2R = 2·4 = 8 см.

Пример 4. Площадь квадрата равна 25 см². Найти диагональ.
Сторона a = √25 = 5 см, тогда d = 5√2 ≈ 7,07 см.

Задачи для самостоятельного решения

  1. Сторона квадрата 8 см. Чему равна его диагональ?
  2. Диагональ квадрата равна 12 см. Найдите сторону и площадь.
  3. Радиус описанной окружности квадрата 3√2 см. Найдите диагональ и сторону.
  4. Периметр квадрата 40 см. Найдите диагональ.

Калькулятор диагонали квадрата

Часто задаваемые вопросы

Как найти диагональ квадрата, зная сторону?

Умножьте сторону на корень из двух: d = a√2.

Как найти сторону квадрата по диагонали?

Разделите диагональ на корень из двух: a = d / √2.

Чему равна диагональ квадрата со стороной 1?

d = √2 ≈ 1,414.

Как диагональ связана с радиусом описанной окружности?

Диагональ равна диаметру описанной окружности: d = 2R.
