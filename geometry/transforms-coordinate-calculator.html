Калькулятор аффинных преобразований на плоскости

Аффинные преобразования включают перенос, поворот, масштабирование (гомотетию), а также их комбинации в виде произвольной матрицы 2×2 и вектора сдвига. Наш калькулятор позволяет применить эти преобразования к заданной точке и увидеть результат на графике вместе с исходной точкой.

  • Перенос (сдвиг): x' = x + dx, y' = y + dy.
  • Поворот вокруг начала координат: x' = x·cosφ - y·sinφ, y' = x·sinφ + y·cosφ (угол в градусах).
  • Масштабирование по осям: x' = x·kx, y' = y·ky.
  • Аффинное преобразование: x' = a₁₁·x + a₁₂·y + tₓ, y' = a₂₁·x + a₂₂·y + tᵧ.

Все результаты сопровождаются пошаговым решением и супер‑простым режимом для новичков.
