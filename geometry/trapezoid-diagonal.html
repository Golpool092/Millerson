Диагонали трапеции

Формулы, свойства, примеры, интерактивный калькулятор. Полный калькулятор трапеции →

Основные формулы диагоналей трапеции

Для произвольной трапеции с основаниями a, b, боковыми сторонами c, d и углами α, β при основании a:

d₁² = a·b + c² + 2a·c·cos α
d₂² = a·b + d² + 2a·d·cos β

Если известны все стороны трапеции, можно найти высоту и проекции, затем диагонали по теореме Пифагора.

Для равнобедренной трапеции (c = d, α = β)

d = √(a·b + c²)

где a, b — основания, c — боковая сторона.

Вычисление диагоналей по четырём сторонам

Пусть a ≥ b. Разность оснований Δ = a − b. Находим проекцию боковой стороны c на основание a:

x = (c² − d² + Δ²) / (2Δ)

Затем высота: h = √(c² − x²).

Тогда диагонали:

d₁ = √((a − y)² + h²), где y = Δ − x
d₂ = √((a − x)² + h²)

Свойства диагоналей трапеции

  • В равнобедренной трапеции диагонали равны.
  • Диагонали трапеции точкой пересечения делятся на отрезки, пропорциональные основаниям.
  • Отрезок, соединяющий середины диагоналей, равен полуразности оснований и лежит на средней линии.

Примеры вычислений

Пример 1 (равнобедренная трапеция). Основания 8 см и 5 см, боковая сторона 4 см. Найти диагональ.
d = √(8·5 + 4²) = √(40 + 16) = √56 ≈ 7,48 см.

Пример 2 (произвольная трапеция). Основания a = 10, b = 6, боковые стороны c = 4, d = 5. Сначала a ≥ b, Δ = 4. Находим x = (4² − 5² + 4²)/(2·4) = (16 − 25 + 16)/8 = 7/8 = 0,875. h = √(4² − 0,875²) = √(16 − 0,7656) = √15,2344 ≈ 3,903. y = 4 − 0,875 = 3,125. d₁ = √((10 − 3,125)² + 3,903²) = √(6,875² + 15,234) = √(47,2656 + 15,234) = √62,5 ≈ 7,91. d₂ = √((10 − 0,875)² + 3,903²) = √(9,125² + 15,234) = √(83,2656 + 15,234) = √98,5 ≈ 9,92.

Пример 3. В равнобедренной трапеции основания 12 и 7, боковая сторона 5. Диагональ: d = √(12·7 + 25) = √(84 + 25) = √109 ≈ 10,44.

Часто задаваемые вопросы

Как найти диагонали трапеции?

В общем случае через стороны и углы. Если известны все стороны, можно найти высоту и проекции, затем по теореме Пифагора.

Как найти диагонали равнобедренной трапеции?

Диагонали равны и находятся по формуле d = √(a·b + c²), где a, b — основания, c — боковая сторона.

Чему равна диагональ равнобедренной трапеции с основаниями 8 и 5 и боковой стороной 4?

d = √(8·5 + 4²) = √(40 + 16) = √56 ≈ 7,48.

Как связаны отрезки диагоналей в точке пересечения?

Они пропорциональны основаниям: отрезки одной диагонали относятся как a : b.
