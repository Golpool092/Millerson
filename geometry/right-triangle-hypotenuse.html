Гипотенуза прямоугольного треугольника

Определение, свойства, формулы, примеры и интерактивный калькулятор. Полный калькулятор прямоугольного треугольника →

Определение

Гипотенуза — это сторона прямоугольного треугольника, лежащая напротив прямого угла. Она является самой длинной стороной прямоугольного треугольника.

Свойства гипотенузы

  • Гипотенуза всегда больше любого из катетов.
  • Квадрат гипотенузы равен сумме квадратов катетов (теорема Пифагора).
  • Центр описанной окружности прямоугольного треугольника лежит на середине гипотенузы, а радиус равен половине гипотенузы.
  • Медиана, проведённая к гипотенузе, равна её половине.
  • Высота, опущенная на гипотенузу, делит её на отрезки, пропорциональные прилежащим катетам.

Формулы для вычисления гипотенузы

Через катеты (теорема Пифагора)

c = √(a² + b²)

Через катет и угол

c = a / sin α
c = a / cos β
c = b / sin β
c = b / cos α

где α — угол, противолежащий катету a, β — угол, противолежащий катету b.

Примеры вычислений

Пример 1. Катеты равны 3 см и 4 см. Гипотенуза: c = √(3²+4²) = √25 = 5 см.

Пример 2. Катет a = 5 см, противолежащий угол α = 30°. Гипотенуза: c = 5 / sin30° = 5 / 0,5 = 10 см.

Пример 3. Катет b = 6 см, прилежащий угол α = 60° (угол α противолежит катету a, значит прилежит к катету b). c = 6 / cos60° = 6 / 0,5 = 12 см.

Связь с тригонометрическими функциями

  • sin α = a/c
  • cos α = b/c
  • tan α = a/b

где α — угол, противолежащий катету a, прилежащий к катету b.

Часто задаваемые вопросы

Что такое гипотенуза?

Гипотенуза — это сторона прямоугольного треугольника, лежащая напротив прямого угла. Она самая длинная сторона.

Как найти гипотенузу по катетам?

По теореме Пифагора: c = √(a² + b²).

Как найти гипотенузу по катету и углу?

Если катет противолежит углу, используйте sin: c = a / sin α. Если катет прилежит к углу — cos: c = a / cos β.

Чему равна медиана, проведённая к гипотенузе?

Медиана равна половине гипотенузы: m = c/2.
