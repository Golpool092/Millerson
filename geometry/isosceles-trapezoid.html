Калькулятор равнобедренной трапеции: площадь, периметр, высота, средняя линия, диагонали, углы

Равнобедренная трапеция — это трапеция, у которой боковые стороны равны. Наш онлайн калькулятор позволяет найти все основные параметры такой трапеции, зная длины оснований и боковой стороны. Вы вводите значения, а калькулятор мгновенно вычисляет высоту (по теореме Пифагора), площадь, периметр, среднюю линию, обе диагонали (они равны) и углы при нижнем основании.

Основные формулы равнобедренной трапеции

Высота: h = √(c² - ((a - b)/2)²), где a, b — основания (a > b), c — боковая сторона.
Площадь: S = (a + b)/2 · h.
Периметр: P = a + b + 2c.
Средняя линия: l = (a + b)/2.
Диагональ: d = √(ab + c²) (обе диагонали равны).
Угол при нижнем основании: α = arctg(2h/(a−b)) (в градусах).

Пример решения

Пример: Основания равнобедренной трапеции a = 8 см, b = 5 см, боковая сторона c = 4 см. Найти все параметры.
Решение: полуразность оснований (a−b)/2 = 1,5 см. Высота h = √(4² − 1,5²) = √(16 − 2,25) = √13,75 ≈ 3,708 см. Площадь S = (8+5)/2·3,708 = 6,5·3,708 ≈ 24,10 см². Периметр P = 8+5+2·4 = 21 см. Средняя линия l = (8+5)/2 = 6,5 см. Диагональ d = √(8·5 + 4²) = √(40+16) = √56 ≈ 7,48 см. Угол при нижнем основании α = arctg(2·3,708/(8−5)) = arctg(7,416/3) ≈ arctg(2,472) ≈ 68°.

Применение в жизни

Равнобедренные трапеции часто встречаются в архитектуре (крыши, мосты), в дизайне мебели, в инженерных конструкциях.
