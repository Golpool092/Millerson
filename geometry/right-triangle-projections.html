Проекции катетов на гипотенузу

Формулы, свойства, примеры, интерактивный калькулятор. Полный калькулятор прямоугольного треугольника →

Формулы проекций катетов

a_c = a² / c
b_c = b² / c
a_c + b_c = c

где a, b — катеты, c — гипотенуза.

Связь с высотой и катетами

h² = a_c·b_c
a² = c·a_c, b² = c·b_c

Свойства проекций

  • Проекции катетов на гипотенузу относятся как квадраты соответствующих катетов: a_c : b_c = a² : b².
  • Проекция большего катета больше.
  • Высота, опущенная на гипотенузу, есть среднее геометрическое проекций: h = √(a_c·b_c).
  • Каждый катет есть среднее геометрическое гипотенузы и своей проекции: a = √(c·a_c), b = √(c·b_c).

Примеры вычислений

Пример 1. Катеты прямоугольного треугольника равны 3 см и 4 см, гипотенуза 5 см. Найти проекции.
a_c = 3²/5 = 9/5 = 1,8 см; b_c = 4²/5 = 16/5 = 3,2 см.

Пример 2. Гипотенуза равна 10 см, проекция одного катета 3,6 см. Найти проекцию второго катета.
b_c = 10 - 3,6 = 6,4 см.

Пример 3. Проекции катетов равны 2 см и 8 см. Найти высоту и катеты.
h = √(2·8) = 4 см; гипотенуза c = 2+8 = 10 см; a = √(10·2) = √20 ≈ 4,47 см; b = √(10·8) = √80 ≈ 8,94 см.

Часто задаваемые вопросы

Что такое проекция катета на гипотенузу?

Проекция катета на гипотенузу — это отрезок гипотенузы, заключённый между вершиной треугольника и основанием высоты, опущенной из прямого угла.

Как найти проекцию катета на гипотенузу?

Проекция катета a равна a_c = a² / c, где c — гипотенуза. Аналогично для катета b: b_c = b² / c.

Чему равны проекции катетов в треугольнике 3-4-5?

a_c = 1,8; b_c = 3,2.

Как связаны проекции с высотой?

h² = a_c·b_c.
