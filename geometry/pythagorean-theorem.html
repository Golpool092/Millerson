Теорема Пифагора

Формулировка

В прямоугольном треугольнике квадрат длины гипотенузы равен сумме квадратов длин катетов.

Формула теоремы Пифагора

c² = a² + b²

где c — гипотенуза, a, b — катеты.

Выражение сторон

c = √(a² + b²)
a = √(c² - b²)
b = √(c² - a²)

Примеры использования

Пример 1. Катеты прямоугольного треугольника равны 3 см и 4 см. Найти гипотенузу.
c = √(3² + 4²) = √(9+16) = √25 = 5 см.

Пример 2. Гипотенуза равна 10 см, один катет 6 см. Найти второй катет.
b = √(10² - 6²) = √(100-36) = √64 = 8 см.

Пример 3. Является ли треугольник со сторонами 5, 12, 13 прямоугольным?
13² = 169, 5²+12² = 25+144 = 169 → равенство выполняется, значит треугольник прямоугольный.

Обратная теорема Пифагора

Если в треугольнике квадрат одной стороны равен сумме квадратов двух других сторон, то такой треугольник является прямоугольным, и угол, лежащий против большей стороны, — прямой.

Это свойство часто используется для проверки, является ли треугольник прямоугольным (например, в задачах на построение).

Доказательства

Существует несколько сотен различных доказательств теоремы Пифагора. Приведём одно из самых наглядных — геометрическое доказательство через площадь квадрата.

Рассмотрим квадрат со стороной (a + b). Внутри него можно расположить четыре равных прямоугольных треугольника с катетами a и b и гипотенузой c. Оставшаяся фигура — квадрат со стороной c. Площадь большого квадрата равна (a + b)² = a² + 2ab + b². С другой стороны, она равна площади четырёх треугольников (4·½ab = 2ab) плюс площадь внутреннего квадрата c². Отсюда a² + 2ab + b² = 2ab + c² → a² + b² = c².

История теоремы

Теорема была известна ещё в древнем Вавилоне и Египте, но её связывают с именем древнегреческого математика Пифагора (VI век до н.э.), который, по преданию, первым дал её строгое доказательство. В настоящее время известно множество доказательств, включая доказательство самого Пифагора (через подобие), алгебраические и геометрические.

Применение

Теорема Пифагора используется в геометрии, физике (разложение векторов), инженерии, навигации, картографии и повседневной жизни для вычисления расстояний, высот, уклонов.

Часто задаваемые вопросы

Что такое теорема Пифагора?

В прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов: c² = a² + b².

Как найти гипотенузу по теореме Пифагора?

Гипотенуза равна квадратному корню из суммы квадратов катетов: c = √(a² + b²).

Как найти катет по теореме Пифагора?

Если известны гипотенуза c и один катет a, то второй катет b = √(c² - a²).

Существует ли обратная теорема Пифагора?

Да: если в треугольнике квадрат одной стороны равен сумме квадратов двух других сторон, то треугольник прямоугольный.
