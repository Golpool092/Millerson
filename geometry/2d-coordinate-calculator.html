Калькулятор координат на плоскости

Инструмент для решения задач аналитической геометрии в двумерном пространстве. Вычисляйте расстояния, середины отрезков, площади треугольников и многоугольников, уравнения прямых, точки пересечения, углы между прямыми, длины векторов, скалярные произведения и углы между векторами. Все результаты сопровождаются пошаговым решением и графической визуализацией на координатной плоскости.

Поддерживаются различные способы задания: по координатам точек, по угловым коэффициентам, по уравнениям. Для многоугольников можно ввести список вершин через запятую.
