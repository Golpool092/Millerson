Справочник по матрицам

Виды матриц

  • Квадратная: число строк = числу столбцов
  • Единичная (E): главная диагональ из 1, остальные 0
  • Нулевая: все элементы 0
  • Диагональная: все элементы вне главной диагонали равны 0
  • Симметричная: A = Aᵀ
  • Треугольная: верхняя или нижняя

Свойства операций

ОперацияСвойство
СложениеКоммутативно: A+B = B+A
УмножениеНе коммутативно: AB ≠ BA (в общем)
Транспонирование(AB)ᵀ = BᵀAᵀ
Обратная(AB)⁻¹ = B⁻¹A⁻¹
det(AB)= det(A)·det(B)

Определитель

2×2: det = ad−bc. 3×3: правило Саррюса или разложение по строке.

Ранг матрицы

Наибольший порядок ненулевого минора. Равен числу линейно независимых строк/столбцов.

Часто задаваемые вопросы

Зачем нужны матрицы?
Для решения систем уравнений, компьютерной графики, машинного обучения, экономических моделей.
Что такое единичная матрица?
Матрица с 1 на главной диагонали и 0 везде. A·E = E·A = A.
Когда матрица невырождена?
Когда её определитель ≠ 0. Только тогда существует обратная матрица.
Что такое след матрицы?
Сумма элементов главной диагонали: tr(A) = a₁₁ + a₂₂ + ... + aₙₙ.
