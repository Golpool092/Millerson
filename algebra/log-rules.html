Правила и свойства логарифмов

Определение логарифма

log_a(x) = y ↔ aʸ = x. Основание a > 0, a ≠ 1; аргумент x > 0.

Натуральный логарифм ln

ln(x) = log_e(x), e ≈ 2.71828... Часто используется в математическом анализе.

ln(1) = 0, ln(e) = 1, ln(e²) = 2.

Десятичный логарифм lg

lg(x) = log₁₀(x). lg(1) = 0, lg(10) = 1, lg(100) = 2, lg(1000) = 3.

Часто задаваемые вопросы

Почему логарифм отрицательного числа не определён?
Показательная функция aˣ всегда положительна, поэтому логарифм определён только для x > 0.
Как вычислить log₅(25)?
log₅(25) = log₅(5²) = 2·log₅(5) = 2·1 = 2.
Что такое натуральный логарифм?
Логарифм по основанию e ≈ 2.71828. Обозначается ln(x).
Как перевести ln в lg?
lg(x) = ln(x) / ln(10) ≈ ln(x) / 2.3026.
