Тождества с многочленами

Формулы сокращённого умножения

(a+b)² = a² + 2ab + b²

(a−b)² = a² − 2ab + b²

a² − b² = (a+b)(a−b)

(a+b)³ = a³ + 3a²b + 3ab² + b³

(a−b)³ = a³ − 3a²b + 3ab² − b³

a³ + b³ = (a+b)(a² − ab + b²)

a³ − b³ = (a−b)(a² + ab + b²)

Формула суммы n-х степеней

aⁿ − bⁿ = (a−b)(aⁿ⁻¹ + aⁿ⁻²b + ... + bⁿ⁻¹)

Квадратный трёхчлен

ax² + bx + c = a(x−x₁)(x−x₂)

где x₁, x₂ — корни (D = b²−4ac ≥ 0)

Бином Ньютона

(a+b)ⁿ = Σ C(n,k)·aⁿ⁻ᵏ·bᵏ

Примеры:

  • (a+b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴
  • (a+b)⁵ = a⁵ + 5a⁴b + 10a³b² + 10a²b³ + 5ab⁴ + b⁵

Часто задаваемые вопросы

Как применять формулу разности квадратов?
a²−b² = (a+b)(a−b). Например, 25−9 = 5²−3² = (5+3)(5−3) = 8·2 = 16.
Как вычислить (x+3)²?
(x+3)² = x² + 2·x·3 + 3² = x² + 6x + 9.
Чем тождество отличается от уравнения?
Тождество верно при любых допустимых значениях переменных. Уравнение — только при конкретных значениях.
Что такое многочлен?
Выражение вида aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀.
