Все формулы алгебры

Формулы сокращённого умножения

Разность квадратов

a² − b² = (a−b)(a+b)

Квадрат суммы

(a+b)² = a² + 2ab + b²

Квадрат разности

(a−b)² = a² − 2ab + b²

Куб суммы

(a+b)³ = a³ + 3a²b + 3ab² + b³

Куб разности

(a−b)³ = a³ − 3a²b + 3ab² − b³

Сумма кубов

a³ + b³ = (a+b)(a² − ab + b²)

Разность кубов

a³ − b³ = (a−b)(a² + ab + b²)

Правила степеней

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿ · bⁿ
a⁻ⁿ = 1/aⁿ
a^(1/n) = ⁿ√a

Правила логарифмов

logₐ(xy) = logₐ(x) + logₐ(y)
logₐ(x/y) = logₐ(x) − logₐ(y)
logₐ(xⁿ) = n · logₐ(x)
logₐ(x) = log(x)/log(a)
aˡᵒᵍₐˣ = x

Прогрессии

Арифметическая прогрессия

aₙ = a₁ + (n−1)·d
Sₙ = n·(a₁+aₙ)/2

Геометрическая прогрессия

bₙ = b₁·q^(n−1)
Sₙ = b₁·(qⁿ−1)/(q−1)

Комбинаторика

Перестановки

P(n) = n!

Размещения

A(n,k) = n!/(n−k)!

Сочетания

C(n,k) = n!/(k!·(n−k)!)

Квадратное уравнение

ax² + bx + c = 0
x = (−b ± √D) / 2a, D = b² − 4ac

Часто задаваемые вопросы

Что такое формулы сокращённого умножения?
Тождества для быстрого раскрытия скобок: (a+b)² = a²+2ab+b².
Зачем нужен справочник формул?
Для быстрого поиска нужной формулы при решении задач по алгебре.
Как запомнить формулы алгебры?
Частое применение, решение задач. Базовые формулы как a²−b²=(a−b)(a+b) нужно выучить наизусть.
Работают ли эти формулы для комплексных чисел?
Большинство формул степеней, логарифмов и прогрессий обобщается на комплексные числа.
